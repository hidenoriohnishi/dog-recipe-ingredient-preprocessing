# 12-2: 海藻ヨウ素推定値の補完

海藻カテゴリ（food_group=09）全58件のうち27件でヨウ素（ID）が欠損（`-`）している。
海藻は犬のレシピにおけるヨウ素の主要供給源であるため、欠損を放置するとレシピ設計に支障が出る。
同系統の既知食品や文献データを根拠に推定値を補完する。

## 入力

- `../12-1-merge-additional-foods/result/final-nutrition-with-egg-shell.csv`
- `iodine-estimates.json` — 補正データ定義

## 処理内容

1. CSVを読み込む
2. `iodine-estimates.json` に定義された food_number を照合
3. ID カラムが欠損（`-` または空）の場合のみ、推定値で上書き
4. 推定値で補完したことを記録する `ID_estimated` カラム（`true` / 空欄）を追加
5. CSVを出力

## 推定方法

`iodine-estimates.json` の各エントリに記載。大きく3種類の方法を使い分ける。

### 1. same_species（同系統マッチング）

同じ海藻種で既にヨウ素の値がある食品から、水分量に基づいて推定する。

**考え方**: 同じ種の乾物換算ヨウ素濃度（μg/100g乾物）はほぼ一定であるため、
水分量から逆算して推定値を求める。

```
推定値 = 乾物換算濃度 × (100 - 水分量) / 100
```

### 2. literature（文献値）

学術論文で報告されている値を使用する。

### 3. taxonomic（分類学的推定）

直接のデータがない場合、同じ分類群（褐藻・紅藻・緑藻）の傾向から推定する。
信頼度は最も低い。
