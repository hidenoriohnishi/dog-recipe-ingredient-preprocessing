# 13-1: 廃棄率の追加

12-1の結果に、元データ（01-csv）から廃棄率（REFUSE）を追加します。

## 概要

元データには「廃棄率」が含まれていますが、04-1のマージ処理で除外されていました。レシピ生成時に廃棄率の情報が必要な場合に備えて、この処理で追加します。

## 入力

- `../12-1-merge-additional-foods/result/final-nutrition-with-egg-shell.csv` – 12-1の結果CSV
- `../01-csv/result/claude-json-header.csv` – 元データCSV（廃棄率を含む）

## 処理内容

1. 12-1の結果CSVを読み込む
2. 元データCSVから廃棄率を読み込む（食品番号をキーに）
3. 12-1の結果に廃棄率の列を追加（`food_group`の後）
4. マージして出力

## 廃棄率について

- **単位**: %
- **説明**: 食品の廃棄部分の割合。可食部100g当たりの値は、廃棄部分を除いた可食部の値です。
- **例**: 廃棄率が20%の場合、購入重量100gに対して可食部は80gとなります。

## 出力

- `result/final-nutrition-with-refuse-rate.csv` – 廃棄率を追加したCSV

## 実行

```bash
pnpm run process:13-1
```
