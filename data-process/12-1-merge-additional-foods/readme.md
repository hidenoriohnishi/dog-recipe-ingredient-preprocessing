# 12-1: 鶏卵殻データの追加

11-1のクリーンアップ済みデータに、12-0の`egg-shell.md`に記載されている卵の殻の成分表情報を追加します。12-0には今後も新しい食材が追加される可能性があります。

## 入力

- `../11-1-clean-data/result/cleaned-final-nutrition.csv` – クリーンアップ済みのMEXT食品データ

## 処理内容

1. 入力CSVを読み込む
2. `egg-shell.md`の情報を基に、鶏卵殻の行を手動で作成
   - food_group: `12`（卵類）
   - food_number: `12024`
   - food_name: `鶏卵　殻`
   - food_name_en: `Chicken egg shell`
   - 栄養成分値は`egg-shell.md`の情報を基に設定
3. CSVに追加して保存

## 栄養成分値

`egg-shell.md`の情報を基に以下の値を設定：

### 基本栄養素
| 成分 | 値 | 備考 |
|------|-----|------|
| WATER | 1.0 g/100g | 乾燥した殻のため低い値 |
| PROT- | 3.0 g/100g | 卵殻膜由来のタンパク質 |
| FAT- | 0 g/100g | 脂質はほぼなし |
| FIB- | 0 g/100g | 動物性のため0 |
| ASH | 96.0 g/100g | 主にカルシウム化合物 |
| ENERC_KCAL | 12 kcal/100g | タンパク質由来のみ |
| ME_KCAL_100G | 0 kcal/100g | 消化されないため |

### ミネラル
| 成分 | 値 | 備考 |
|------|-----|------|
| CA | 38,000 mg/100g | 主成分 |
| MG | 385 mg/100g | 370-400の中央値 |
| P | 155 mg/100g | 150-160の中央値 |
| NA | 160 mg/100g | |
| K | 45 mg/100g | 40-50の中央値 |
| FE | 1.5 mg/100g | 1.0-2.0の中央値 |
| ZN | 0.3 mg/100g | 0.1-0.5の中央値 |
| MN | 0.1 mg/100g | |
| CU, ID, SE | - | データなし |

### ビタミン・アミノ酸・脂肪酸
- ビタミン類：データなし（卵殻にはほぼ含まれない）
- アミノ酸類：データなし
- 脂肪酸類：データなし

## 出力

- `result/final-nutrition-with-egg-shell.csv` – 鶏卵殻の行を追加したCSV

## 実行

```bash
pnpm run process:12-1
```
