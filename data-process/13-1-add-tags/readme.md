# 13-1: タグ情報の追加

12-1の結果データに、AIを使用して以下の3つのフィールドを追加します：

1. **タグネーム**: この食材を最も端的に表す名前。ユーザがその食材を最も自然にそう呼ぶもの（例：「さば」「すもも」「トマト」「ごはん」）。他と重複しても良い。
2. **差分**: タグネームの性質上、複数の食材が同じタグネームに当たる場合がある。そこで、タグネームを指定して食材を選んだ時、複数の同一のタグネームを持つもののなかから何を選んだかが判別できる必要がある。そのために「タグネーム」と「差分」は一緒に表示されることが多い。タグネームが大きく表示されて、差分は小さく表示される。
3. **サーチキーワード**: 大量にある食材の中でユーザがこの食材を検索する時に使う検索ワード。ひらがな、かたかなの違いはプログラムで吸収される（平仮名→片仮名、片仮名→平仮名ともに）。タグキーワードは自動で検索条件に含まれるため、含まなくて良い。主に漢字や表記揺れ、シノニムなどを中心にリストアップ。

## 入力

- `../12-1-merge-additional-foods/result/final-nutrition-with-egg-shell.csv` – 12-1の結果データ

## 処理内容

1. 入力CSVを読み込む
2. GPT4.1を使用して、バッチで30食材ずつ処理
3. バッチ間のオーバーラップは5個（前のバッチの最後5個を次のバッチの最初に含める）
4. バッチごとに結果を出力
5. 後のバッチは前のバッチの最後の5個を読み込んで参考にする
6. 各食材にタグネーム、差分、サーチキーワードの3つのフィールドを追加

## 出力

- `result/final-nutrition-with-tags.csv` – タグ情報を追加したCSV
- `result/batches/` – バッチごとの結果JSONファイル
- `result/progress.json` – 進捗管理ファイル

## 実行

```bash
pnpm run process:13-1
```
