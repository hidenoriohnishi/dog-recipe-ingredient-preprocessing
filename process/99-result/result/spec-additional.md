# 線型計画法（LP）モデル詳細仕様

本ドキュメントは、レシピ生成アルゴリズムの完全な仕様を記載します。
`spec.md`に記載の基本仕様に加え、実装で採用したチューニングと制約を網羅します。

---

## 1. LPモデル概要

### 1.1 最適化問題の定式化

```
minimize: Σ cost_i × x_i + Σ penalty_j × slack_j
subject to: 各種制約
```

- **決定変数**: 各食材の使用量（100g単位）
- **目的関数**: コストの最小化（低スコア食材にペナルティ）
- **制約**: HARD制約（必須）とSOFT制約（スラック変数によるペナルティ付き）

### 1.2 変数の定義

各食材 `i` は変数 `ing_i` として表現されます：

| 項目 | 値 |
|------|-----|
| 変数名 | `ing_i`（i = 0, 1, 2, ...） |
| 単位 | **100gあたりの単位数** |
| グラム換算 | `grams = solution['ing_i'] × 100` |
| 採用閾値 | `solution['ing_i'] > 0.1`（10g以上を採用） |
| 最小表示 | `grams > 1`（1g以上を表示） |

---

## 2. 目的関数（コスト最小化）

### 2.1 コスト計算式

```typescript
cost_i = 1 + scorePenalty
scorePenalty = (10 - score_i) × 10
```

### 2.2 スコア別コスト表

| 食材スコア | scorePenalty | cost | 効果 |
|-----------|-------------|------|------|
| 10 | 0 | 1 | 最優先で選択される |
| 9 | 10 | 11 | 優先的に選択される |
| 8 | 20 | 21 | 標準的なコスト |
| 7 | 30 | 31 | 選択されにくい |
| 6 | 40 | 41 | かなり選択されにくい |
| 5以下 | 50+ | 51+ | ほぼ選択されない |

### 2.3 設計意図

- 高スコア食材（犬にとって安全で栄養価が高い）を優先的に選択
- 同等の栄養価を満たす場合、スコアの高い食材が選ばれる
- 平均スコア9.0以上を目指したチューニング

---

## 3. HARD制約（必須制約）

HARD制約は必ず満たされなければならず、満たせない場合は「解なし」となります。

### 3.1 総重量制約

```typescript
total_weight ≤ (bodyWeightKg × 1000 × 0.05) / 100
```

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 上限率 | 5% | 犬の体重に対する1日の食事量上限 |
| 換算 | 体重kg × 50 | 体重1kgあたり50gまで |

**例**: 10kgの犬 → 最大500gの食事

**設計理由**:
- 低カロリー食材が大量に選ばれる問題を防止
- 犬の胃の容量を考慮した現実的な制約
- 一般的な手作り食の目安（体重の2-5%）の上限を採用

### 3.2 エネルギー制約

```typescript
MER × 0.90 ≤ energy ≤ MER × 1.10
```

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 許容範囲 | ±10% | MERを中心とした許容誤差 |

### 3.3 たんぱく質制約

```typescript
protein ≥ standards.protein_g × merFactor
```

| ライフステージ | 最小値 (g/1000kcal) |
|---------------|-------------------|
| ADULT | 45.0 |
| PUPPY | 56.3 |

### 3.4 脂質制約

```typescript
standards.fat_g × merFactor ≤ fat ≤ standards.fat_g_max × merFactor
```

| ライフステージ | 最小値 (g/1000kcal) | 最大値 (g/1000kcal) |
|---------------|-------------------|-------------------|
| ADULT | 13.8 | 33.3 |
| PUPPY | 21.3 | 38.9 |

**最大値の根拠**:
- ADULT: 総カロリーの30%（一般的ガイドライン上限）
- PUPPY: 総カロリーの35%（成長期の許容上限）

### 3.5 カルシウム制約

```typescript
standards.calcium_g_min × merFactor ≤ calcium ≤ standards.calcium_g_max × merFactor
```

| ライフステージ | 最小値 (g/1000kcal) | 最大値 (g/1000kcal) |
|---------------|-------------------|-------------------|
| ADULT | 1.25 | 6.25 |
| PUPPY | 3.0 | 4.5 |

### 3.6 リン制約

```typescript
standards.phosphorus_g_min × merFactor ≤ phosphorus ≤ standards.phosphorus_g_max × merFactor
```

| ライフステージ | 最小値 (g/1000kcal) | 最大値 (g/1000kcal) |
|---------------|-------------------|-------------------|
| ADULT | 1.00 | 4.0 |
| PUPPY | 2.5 | 4.0 |

### 3.7 ナトリウム制約

```typescript
standards.sodium_g_min × merFactor ≤ sodium ≤ standards.sodium_g_max × merFactor
```

| ライフステージ | 最小値 (g/1000kcal) | 最大値 (g/1000kcal) |
|---------------|-------------------|-------------------|
| ADULT | 0.20 | 1.5 |
| PUPPY | 0.80 | 1.5 |

**最大値の根拠**: NRC参考、最小値の約7.5倍

### 3.8 スコア平均制約

```typescript
score_avg ≥ 0
// 各食材の寄与: score_avg = score_i - 9.0
```

**計算式**:
```
Σ((score_i - 9.0) × x_i) ≥ 0
```

これは以下と等価:
```
重み付き平均スコア ≥ 9.0
```

### 3.9 ω6:ω3 比率制約

```typescript
omega_ratio ≤ 0
// 各食材の寄与: omega_ratio = omega6_i - 10 × omega3_i
```

**計算式**:
```
Σ(omega6_i × x_i) - 10 × Σ(omega3_i × x_i) ≤ 0
```

これは以下と等価:
```
ω6:ω3 ≤ 10:1
```

**設計理由**: AAFCOの公式は30:1だが、実用的には10:1が推奨される

### 3.10 Ca:P 比率制約

```typescript
ca_p_ratio_min ≥ 0  // 各食材: ca - p ≥ 0
ca_p_ratio_max ≤ 0  // 各食材: ca - 2×p ≤ 0
```

**計算式**:
```
Σ(Ca_i × x_i) ≥ 1.0 × Σ(P_i × x_i)  // Ca:P ≥ 1:1
Σ(Ca_i × x_i) ≤ 2.0 × Σ(P_i × x_i)  // Ca:P ≤ 2:1
```

### 3.11 単一食材エネルギー上限

```typescript
// 各食材ごとに個別の制約
ing_i_energy_max ≤ MER × 0.5
```

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 上限率 | 50% | 1食材が総エネルギーの半分を超えない |

**設計理由**:
- 栄養バランスの偏りを防止
- アレルギーリスクの分散
- 食材の多様性確保

## 4. SOFT制約（ペナルティ付き制約）

SOFT制約は満たせなくてもペナルティを支払うことで解が得られます。
スラック変数により、制約違反のコストを目的関数に加算します。

### 4.1 スラック変数の仕組み

```typescript
// 最小値制約の場合
if (constraint.min !== undefined) {
  model.constraints[name] = { min: constraint.min };
  model.variables[`slack_${name}`] = {
    cost: constraint.penalty,
    [name]: 1,  // スラック変数が制約を緩和
  };
}

// 最大値制約の場合
if (constraint.max !== undefined) {
  model.constraints[`${name}_max`] = { max: constraint.max };
  model.variables[`slack_${name}_max`] = {
    cost: constraint.penalty,
    [`${name}_max`]: 1,
  };
}
```

### 4.2 ペナルティ値の設定

| ペナルティ | 栄養素 | 理由 |
|-----------|--------|------|
| **10** | リノール酸 | 必須脂肪酸（重要） |
| **10** | α-リノレン酸（PUPPY） | 必須脂肪酸（重要） |
| **10** | EPA+DHA（PUPPY） | 必須脂肪酸（重要） |
| **5** | その他すべて | 標準ペナルティ |

### 4.3 ペナルティ5の制約一覧

| 栄養素 | 制約タイプ | 備考 |
|--------|-----------|------|
| カリウム | min | |
| マグネシウム | min | |
| 鉄 | min | |
| 亜鉛 | min | |
| 銅 | min | |
| マンガン | min | |
| ヨウ素 | min / max | 上限あり |
| セレン | min / max | 上限あり |
| ビタミンA | min / max | 上限あり |
| ビタミンD | min / max | 上限あり |
| ビタミンE | min | |
| ビタミンB1 | min | |
| ビタミンB2 | min | |
| ナイアシン | min | |
| パントテン酸 | min | |
| ビタミンB6 | min | |
| 葉酸 | min | |
| ビタミンB12 | min | |
| コリン | min | |

## 5. 単位変換

### 5.1 MEXT → AAFCO 変換

食材データベース（MEXT）の値をAAFCO基準の単位に変換します。

#### ビタミン変換

| ビタミン | MEXT単位 | AAFCO単位 | 変換式 |
|---------|---------|----------|--------|
| ビタミンA | μg (レチノール) | IU | `IU = retinol_ug / 0.3` |
| ビタミンD | μg | IU | `IU = vitd_ug × 40` |
| ビタミンE | mg (αトコフェロール) | IU | `IU = tocpha_mg × 1.49` |

#### ミネラル変換

| ミネラル | MEXT単位 | LP単位 | 変換式 |
|---------|---------|--------|--------|
| Ca, P | mg/100g | g/100g | `÷ 1000` |
| K, Na, Mg | mg/100g | g/100g | `÷ 1000` |
| Fe, Zn, Cu, Mn | mg/100g | mg/100g | そのまま |
| I, Se | μg/100g | mg/100g | `÷ 1000` |

#### 脂肪酸変換

| 脂肪酸 | MEXT単位 | LP単位 | 変換式 |
|--------|---------|--------|--------|
| すべて | mg/100g | g/100g | `÷ 1000` |

### 5.2 MEXT特殊記号の処理

```typescript
// Tr（微量）の処理
if (str === 'Tr' || str === '(Tr)') return 0.001;

// 未測定の処理
if (str === '' || str === '-') return 0;

// 括弧付き数値の処理
const num = parseFloat(str.replace(/[()]/g, ''));
```

## 6. merFactor（日量換算係数）

AAFCO基準は「1000kcal MEあたり」で定義されているため、日量に変換します。

```typescript
merFactor = MER / 1000
```

**例**: MER = 800kcal の場合
- merFactor = 0.8
- たんぱく質最小値 = 45.0 × 0.8 = 36.0g/日

---

## 7. MER（1日必要エネルギー）計算

### 7.1 RER計算式

```typescript
RER = 70 × (body_weight_kg ^ 0.75)
```

### 7.2 係数表

| 条件 | 係数 | 優先順位 |
|------|------|---------|
| PUPPY | 2.0 | 1（最優先） |
| INACTIVE | 1.1 | 2 |
| WORK_LIGHT | 1.8 | 3 |
| WORK_MODERATE | 3.0 | 4 |
| WORK_HEAVY | 7.0 | 5 |
| NEUTERED | 1.5 | 6（デフォルト） |
| INTACT | 1.7 | 6（デフォルト） |

### 7.3 MER計算式

```typescript
MER = RER × factor
```

**例**: 体重10kgの去勢済み成犬
- RER = 70 × (10^0.75) = 70 × 5.62 = 393.7 kcal
- MER = 393.7 × 1.5 = 590.5 kcal

## 8. 食材フィルタリング

### 8.1 ME > 0 フィルタ

```typescript
if (nutrients.me100g <= 0) return;
```

代謝エネルギーが0以下の食材はLPモデルから除外されます。

## 9. 制約の全体像（図解）

```
┌─────────────────────────────────────────────────────────────┐
│                    目的関数                                  │
│   minimize: Σ (1 + (10-score)×10) × x_i + Σ penalty × slack │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                   HARD制約（必須）                           │
├─────────────────────────────────────────────────────────────┤
│ • 総重量 ≤ 体重×5%                                          │
│ • エネルギー: MER±10%                                       │
│ • たんぱく質 ≥ min                                          │
│ • 脂質: min ≤ fat ≤ max                                     │
│ • カルシウム: min ≤ Ca ≤ max                                │
│ • リン: min ≤ P ≤ max                                       │
│ • ナトリウム: min ≤ Na ≤ max                                │
│ • スコア平均 ≥ 9.0                                          │
│ • ω6:ω3 ≤ 10:1                                              │
│ • Ca:P = 1:1 〜 2:1                                         │
│ • 各食材エネルギー ≤ MER×50%                                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                  SOFT制約（ペナルティ付き）                  │
├─────────────────────────────────────────────────────────────┤
│ penalty=10:                                                 │
│   • リノール酸 ≥ min                                        │
│   • α-リノレン酸 ≥ min (PUPPY)                              │
│   • EPA+DHA ≥ min (PUPPY)                                   │
├─────────────────────────────────────────────────────────────┤
│ penalty=5:                                                  │
│   • ミネラル（K, Mg, Fe, Zn, Cu, Mn）≥ min                  │
│   • ミネラル（I, Se）min ≤ x ≤ max                          │
│   • ビタミン（A, D）min ≤ x ≤ max                           │
│   • ビタミン（E, B群, コリン）≥ min                         │
└─────────────────────────────────────────────────────────────┘
```

## 13. 未実装・OFF扱いの制約

以下の項目は`aafco.ts`に定義されていますが、LPモデルには含まれていません。

### 13.1 塩素（Chloride）

| 項目 | 値 |
|------|-----|
| 定義 | `chloride_g_min`, `chloride_g_max` in `aafco.ts` |
| LP実装 | **なし** |
| 理由 | MEXTデータベースにCl値がない |
| 推定 | レシピ出力時に `Cl ≈ Na × 1.5` で推定表示 |

### 13.2 必須アミノ酸

| 項目 | 値 |
|------|-----|
| 定義 | 10種類すべて `aafco.ts` に定義 |
| LP実装 | **なし**（OFF扱い） |
| 理由 | アミノ酸データは84%の食品にしか存在しない |
| 表示 | レシピ出力時に参考値として計算・表示 |

### 13.3 カリウム・マグネシウム等のミネラル上限

| 項目 | 値 |
|------|-----|
| 定義 | AAFCOに上限なし |
| LP実装 | **最小値のみ**（SOFT制約） |
