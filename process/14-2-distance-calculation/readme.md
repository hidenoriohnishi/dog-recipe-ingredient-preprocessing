# 14-2: 距離計算・食材マッチング

14-1で生成したラベルのembeddingと、13-2で生成した食材のembeddingを使って、コサイン距離を計算し、手動で食材を選択してマッピングします。

## 目的

レシピで使用される食材ラベル（例：「切り干し大根」）と、MEXTデータの食材を紐づけます。

## 入力

- `../14-1-label-embedding/result/label-embeddings.json` – ラベルのembeddingデータ
- `../13-2-embedding/result/embeddings.json` – 食材のembeddingデータ

## 処理内容

1. ラベルのembeddingsを読み込む
2. 食材のembeddingsを読み込む
3. 各ラベルに対して:
   - 全食材とのコサイン距離を計算
   - 距離の近い順に9個の候補を表示
   - ユーザーが手動で選択
4. 結果をJSONファイルに保存

## 出力

- `result/ingredient-mapping.json` – 食材マッピング結果
- `result/progress.json` – 処理進捗

## 実行

```bash
pnpm run process:14-2
```

## 操作方法

各ラベルに対して候補が9個表示されます。

### 入力例

- `1` → 1番目の候補を選択
- `213` → 2番目→1番目→3番目の順で選択（優先順位付き）
- `Enter` → 何も選択せずに次へ
- `s` → スキップ（保存しない）
- `q` → 終了

### 出力例

```
==================================================
[1/200] 切り干し大根
パス: 野菜 > 切り干し大根
==================================================

候補:
  1. [06055] 切り干しだいこん　乾
     距離: 0.1234 | 切り干しだいこん だいこん dried radish...
  2. [06056] 切り干しだいこん　ゆで
     距離: 0.1567 | 切り干しだいこん ゆで だいこん...
  ...

選択 (数字/Enter/s/q): 12
```

この例では、1番目と2番目が選択され、1番目が優先順位1、2番目が優先順位2として保存されます。

## 注意事項

- 処理は中断しても、progress.jsonに進捗が保存されているため、再実行時に続きから処理されます
