# 13-1: 代表食材マーキング

食材リストから「代表食材」を識別してマークを付けます。

## 目的

MEXTデータには同じ食材の多数のバリエーションが含まれています：
- 「鶏もも 生」「鶏もも 焼き」「鶏もも ゆで」
- 「おおむぎ 七分つき押麦」「おおむぎ 押麦 乾」「おおむぎ 押麦 めし」

ユーザーが「鶏もも」を検索したとき、最初に表示すべき「代表食材」を特定します。
代表食材以外は、代表食材を通じて参照されるバリエーションとして扱います。

## 入力

- `../12-1-add-egg-shell/result/final-nutrition-with-egg-shell.csv`

## 処理内容

1. CSVを読み込む
2. バッチ処理（30食材ずつ、20食材オーバーラップ）
   - MEXTデータは順番に並んでおり、類似食材は近くにある
   - オーバーラップにより、同じ食材グループが分割されるのを防ぐ
3. AIが各バッチ内で「代表食材」を判定
   - 代表食材: その食材群の基本形（例：「鶏もも」）
   - バリエーション: 調理法・加工法違い（例：「鶏もも 焼き」）
4. 結果をCSVに追加

## 代表食材の判定基準

AIは以下の基準で代表食材を判定します：

1. **基本形を優先**: 調理状態（生・焼き・ゆで等）がないものを優先
2. **汎用性を優先**: より一般的な形態を優先
3. **同じbaseNameで複数ある場合**: 最もシンプルな記述を代表とする

## 出力

- `result/final-nutrition-with-canonical.csv` – `is_canonical`列を追加したCSV
- `result/canonical-mapping.json` – 代表食材マッピング（参照用）
- `result/progress.json` – 処理進捗

## 追加される列

| 列名 | 説明 |
|------|------|
| `is_canonical` | TRUE: 代表食材、FALSE: バリエーション |

## 実行

```bash
pnpm run process:13-1
```
